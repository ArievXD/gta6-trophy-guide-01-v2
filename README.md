Leonida Trophy Guide — an offline guide and tracker for all 55 GTA 6 PS5 trophies (1 Platinum, 2 Gold, 6 Silver, 46 Bronze). Every trophy has an own-words guide with cited sources, a 5-stage roadmap to the Platinum with the one missable trophy flagged, and a tracker that saves your progress in the browser — with filters (story / missable / collectibles / activities / online), search, export/import, and a spoiler setting that hides un-earned story trophies. Fully offline static web app — no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
